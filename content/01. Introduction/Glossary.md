[[Glossary]]
[[introduction]]

- **Block Pattern:** A pre-designed, ready-to-use collection of layout blocks that you can insert into a page with a single click and customize.

- **Synced Pattern:** A global block layout that, when edited in one place, instantly updates across every single page where it is deployed.

- **Template Part:** A structural block area, such as a site header or footer, used to manage layout elements across your entire theme.

- **Block Theme:** A modern theme built entirely using blocks, allowing you to edit the global header, footer, and templates without touching code.

- **Custom Post Type (CPT):** A way to register content types beyond standard pages and posts, often added automatically by plugins for things like products or portfolios.

- **Taxonomy:** The overarching classification system used to group content together, which includes default categories and custom organization groupings.

- **Site Health:** A built-in dashboard tool that monitors your website’s performance, security status, and technical configuration, offering optimization recommendations.

- **Child Theme:** A sub-theme that inherits all the styling of a parent theme, allowing you to safely make customizations without losing them during updates.

- **Host:** A server that holds or host space for your website every site on the internet needs to be hosted and have a unique _domain_

- **`functions.p:** A specific theme file that acts like a local plugin, allowing you to paste code snippets to add custom features to your site.

- **Multisite:** A built-in feature that allows you to create and manage an entire network of multiple virtual websites from a single WordPress installation..

- __Domain__: A domain is a unique address for your site and it's location on the host.
