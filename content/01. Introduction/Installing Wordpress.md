[[introduction]]


Because wordpress is made for hosting and managing content it is not a program you install directly on your computer unless you have a host already planned you can build your website for free using *local* it is build to act as a local server without having to pay for webhost. It has the same functionality as if connected to a live server such as bluehost. 

1. You would first visit [Local](https://localwp.com) 
2. Download for free. Local will always remain free
3. Select "Download for free"
4. After completing the install and opening local open and select create a new site 
5. Type a name for your site no need to change the advance option
6. Select continue 
7. Enter a username and password for your site take note of it
8. Enter your email address. 
9. - Select "Add Site" to let the software automatically download and configure WordPress.
10. "Open Site" to view the front-end design in your browser.
11. "WP Admin" to open the login dashboard where you can enter your newly created username and password to start editing
