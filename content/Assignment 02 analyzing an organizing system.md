### Online Resource 
### [w3schools.com](https://www.w3schools.com/)

I use W3Schools a lot as I practice code and teach myself PHP in my spare time. It has tutorials on programming languages and adjacent topics such as intro to programming, data science, AI, and Excel. Across the top, it lists each of the main topics, and once you click into one, it opens a sidebar with related subtopics. There is also a search bar for less popular or less common topics that are likely on the site but not listed in the common sidebar. I personally have never had trouble finding anything about any language I am practicing or learning.
### Use of Interactions 
W3Schools is a tutorial site. I don't believe you could learn from scratch to be a competent coder solely on W3Schools, but if you have already taken a course and want to get better, it is an excellent resource, primarily for fact-checking. W3Schools also has built-in practice for each lesson with an example and a mini sandbox to test small samples of code without breaking anything.

### Classification system 
W3Schools uses a hierarchical, topic-based classification system. At the top level, you have the main technology (e.g., HTML, CSS, Python), followed by individual properties or subtopics (e.g., Python operators). At the end of the articles, there are suggestions for related articles. Within each primary topic, such as _Python List_, there are about 13 related subtopics. The structure of the site is well organized, if a bit overwhelming. Also, as a learner, you might not know the exact term you are looking for, so browsing through topics manually might cause you to miss the lesson you need. However, W3Schools has very good SEO, so searching Google will likely lead you directly to one of their specific lessons.

### Relations 
An interesting observation is that none of the main topics at the top of the page intersect with each other, even though in programming many languages frequently overlap (most notably CSS and HTML). Instead, the tutorials treat each language individually. The organization of topics follows the order you would learn them in a class, arranged by complexity, allowing you to select "Next" and browse through them sequentially. However, you can only click "Next" through the selected language track (such as Python). At the end of the Python course, it presents a call to action to buy additional lessons for $100. To start a new topic, you must navigate back to the top menu and select a new language.
