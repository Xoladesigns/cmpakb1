### Choosing a Theme 
There are classic themes in WP that do not use block editors, which limit the ease and flexibility of customization. You can tell the difference between a block theme and a classic theme by the options available under Appearance. You will see Customizer instead of Editor, which you will see in block themes. Hybrid themes use elements of both a block theme editor and a classic theme Customizer.

To add a new theme, select Appearance and Themes. There is an Add Themes button that takes you to the WP repository, where you can browse through hundreds of themes. What you need in a theme and how you choose one is up to the site you want to build and its overall aesthetics. You can click on a theme and choose Install, and it will show up with your other themes in WP. After installation, you can select Activate to apply the theme to your website.

Themes sometimes require updating. You will be notified in multiple places when a theme needs to be updated. You can see a list of updates and select the theme to update. You can also enable auto-updates for themes.
