WP on it's own is a powerful content management system however one of the biggest advantages is the ability to extend the functionality of a website. An innumerable number of plugins exist in wordpress that can change your site such as adding WooCommerce to make a medium size site.  They can add additional security memberships, SEO and an endless supply of them.  Similar to themes there is a directory of plugins within wordpress repository there are also premium themes. You can search the repository by typing keywords 

Though plugins in the repository are vetted and have strict rules before installing you should consider: 
1. **Star Rating**: This requires no explanation 
2. **Last Update**: This is the last update that plugin creator updated it. It should be relatively recent. 
3. **Active Installs**: The active installs are the amount of people using the plugin high numbers indicate a well liked and supported plugin. 
4. **Compatibility**: Make sure it is compatible with both your version of wordpress and your theme
Once you confirm your plugin you can download the plugin. It will show in the plugins option on the side toolbar in WP there you can update, delete and manage the settings.  You should be careful with the number plugins because it makes it harder to find the plugin issues if any occur, also to many plugins can cause performance issues.
