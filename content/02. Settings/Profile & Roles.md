The default roles in WP are: 

Administrator:  The administrator is assigned by default who can edit the backend sites without restriction and assigns the other roles. The admin is the only role that can edit themes, plugins and code. 

Editor:  As the name implies the editor can edit the post of other users and also manage post such as deleting post.  Editors cannot install themes, plugins, or updates

Author:  Can publish and edit their own post. 

Contributor:  Can write and manage post but require review from an admin or editor to publish

Subscriber:  Can only manage their profiles they can read all published post and is not used on many sites
