### Privacy Page 
A privacy page is a legal requirement especially if users will be providing information. Wordpress has a template but you can customize for your website. You can calls add a privacy footer to each page on your website so that it can be part of the quick links 

### Media 
WP has 3 sizes that it will use for an image, thumbnail, medium and large the file size is usually reduced size to improve website performance. 
- Large images should be should be used as major images banners or solo post 
- Medium images should be used inside of post along with other media
- Thumbnail as a preview image, list or widgets 
Settings allows you to choose the default setting for image sizes WP will also sort files by date.  You also have the option to have all images in one image folder.
