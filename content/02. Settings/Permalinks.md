Permeant links point to a specific page or post user friendly names are a part of a permalink it is called a slug. 

Settings> Permalinks 
The slug of a post will include the date but you can change it to preselected options in settings or create a customer template. You can edit any slug to make it more user friendly. You can change the permalink but it should only be done when the post is new. If you change the permalink to an old post it will affect the website traffic, it can be managed with a plugin if you change the permalinks. 

Because every post and page in WP has a permalink these settings do not have to be adjusted for each post instead it sets the overall settings of your permalinks and slugs to a default user friendly setting.
